## 🏝️ ULTRA-PREMIUM UX/UI INSPIRATION

- **Colour**: Vibrant "Stripe Blur" gradients (purples, pinks, cyans) against stark white or deep indigo
- **Layout**: "Slope" section designs, 12-column precision grids with pixel-perfect spacing
- **Hero**: Bold single-line value proposition + two CTAs (primary + secondary)
- **Key patterns**:
  - Animated gradient backgrounds
  - Side-by-side feature showcases
  - Trust logos ("Powering businesses of all sizes")
  - Use case segmentation (Enterprise, Startup, SaaS)

### Linear
- **Typography**: Inter with extreme precision — hierarchy through weight + gray intensities
- **Colour**: Dark mode pioneer (#0B0C0D deep grays) with subtle purple/blue glowing accents
- **Layout**: "Bento box" grids with tight cards, 1px borders, glassmorphism
- **Key patterns**:
  - Numbered steps (1.0 Intake → 2.0 Plan → 3.0 Build → 4.0 Reviews)
  - Code diffs as visual elements
  - Structural diffs for showing change
  - Glowing borders & ultra-fast page transitions
  - "Purpose-built" positioning language

## 🎯 KEY DESIGN PRINCIPLES FOR TERRATREKS

### 1. Typography System
- **Headlines**: Playfair Display (serif) — large, confident, editorial
- **Body**: Outfit/Inter (sans-serif) — clean readability
- **Accents**: ALL-CAPS with extreme letter-spacing (tracking-[0.3em]+) for labels/categories
- **Sizes**: Hero H1 should be 6xl-9xl. Section H2 should be 5xl-7xl.

### 2. Color Palette (Current — validated as excellent)
- Primary: #1B3022 (Deep Safari Green) ✅
- Secondary: #C6935C (Safari Gold) ✅ — similar to Singita's #CB9275
- Background: #FDFBF7 (Bone/Parchment) ✅
- Earth: #4F311C ✅
- Accent: #3A5A40 (Moss) ✅
- **ADD**: Consider a deep charcoal (#1A1A1A) for dark sections (Linear-inspired)

### 3. Layout Patterns to Adopt
- **Magazine editorial grids** (Natural World Safaris)
- **Quote-first testimonials** (ROAR Africa style)
- **Numbered process steps** (Scott Dunn + Linear style)
- **Award/trust badge strips** (Wilderness style)
- **Collection galleries** (Singita lodge cards)
- **Stats counters** (Wilderness: 55 Camps / X Countries / etc.)

### 4. Interaction Design
- **Button hover**: Outlined → filled (Singita pattern), transition 0.3-0.5s ease
- **Card hover**: Subtle lift (-translate-y-2), scale(1.02), shadow increase
- **Image hover**: Grayscale → color (andBeyond) or slow scale(1.05)
- **Scroll animations**: Cubic-bezier(0.22, 1, 0.36, 1) — smooth, elegant reveals
- **Navigation**: Glassmorphism on scroll (already implemented ✅)

### 5. Language & Copywriting Patterns
- "Begin the conversation" not "Contact Us"
- "Inquire Now" or "Design My Journey" not "Book Now"
- "Journey Designers" not "Travel Agents"
- "Investment" not "Price"
- "Signature Journeys" not "Packages"
- Heritage storytelling ("Established 2024")
- Mission-driven sections (conservation, community)
